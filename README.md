# Al Noor Loyalty — New Project

A clean, independent UI foundation for the Al Noor Loyalty concept.

## Three separate experiences

### Customer
Login → Register → Home → Loyalty Card/QR → Rewards → Profile

### Staff
Login → Scan Customer → Customer Found → Add Points / Redeem → Transactions → Staff Profile

### GM
Login → Dashboard → Members → Locations → Reports → Settings

## Run
Open `index.html` in a browser or publish the folder on GitHub Pages.

## Data
This version starts in localStorage demo mode so the manager can review the complete UI before database integration.

## Next integration
Connect Supabase after the visual version is approved. Keep service-role credentials off the browser; use only a public/anon key client-side with Row Level Security.

## Android
This is the clean web/PWA foundation. A native Android wrapper/APK should be created after the UI is approved.
